01 Open source 2026

Alcove

Alcove replaces the file tree with shelves, and each notebook keeps its binding wherever it moves. Pages stay directly editable; WebGL appears only during a turn. An optional, source-aware agent previews page drafts before insertion, while the library remains stored locally.

View source↗

How Alcove works

The shelf is the file browser.

Bookcases, floors, and visible spines are the library’s structure. There is no separate file tree, and the library stays on the reader’s computer.

PixiJS shelf · local SQLite library

A binding belongs to the book.

Each notebook keeps its cloth or leather, cover, rules, emblem, paper, and page edges—even when it moves to another room.

Authored bindings · portable identity

Editable at rest. Physical while moving.

Pages remain crisp, selectable DOM while you write, then become a WebGL curl only for the turn.

TipTap editor · WebGL page physics

Help stays optional—and reviewable.

The optional in-book agent works from sources you choose and previews every draft before insertion. It remains inactive until you add a key and start a task.
